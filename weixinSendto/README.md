# 将微信消息转发到群组

* 适用于window下微信。
* 模拟右键点击
* 查找点击 `转发...` 菜单
* 输入temp，点击第一个匹配的群
* 点击`发送`按钮

快捷键： `Win+Shift+A`

## 配置说明

配置文件位于 `weixinSendto/App.config`，所有配置项均为 `Application` 作用域，修改后需重新编译。

| 配置项 | 类型 | 默认值 | 说明 |
| ------ | ---- | ------ | ---- |
| `isDebug` | bool | `False` | 调试模式，开启后会输出额外日志 |
| `key` | string | `temp` | 转发时输入的搜索关键词，用于匹配目标群组 |
| `pointCount` | string | `4,8,9,21,22,10,8,25,9,15,9,21,11,15,23,16` | 右键菜单中"转发"按钮的像素特征模板（每行黑点数量，逗号分隔） |
| `dx` | int | `5` | 截图区域相对鼠标位置的 X 偏移量 |
| `dy` | int | `105` | 截图区域相对鼠标位置的 Y 偏移量（从菜单下方开始截取） |
| `imgWidth` | int | `100` | 截图区域宽度（像素） |
| `imgHeight` | int | `200` | 截图区域高度（像素） |
| `search_x` | int | `140` | 搜索结果第一个匹配项相对窗口左上角的 X 坐标 |
| `search_y` | int | `125` | 搜索结果第一个匹配项相对窗口左上角的 Y 坐标 |
| `sendbtn_x` | int | `470` | 发送按钮相对窗口左上角的 X 坐标 |
| `sendbtn_y` | int | `540` | 发送按钮相对窗口左上角的 Y 坐标 |

### 工作流程

1. 鼠标悬停在要转发的微信消息上，按下 `Win+Shift+A`
2. 程序模拟右键点击，弹出消息菜单
3. 截取菜单下方区域的屏幕图像，进行二值化处理
4. 通过 `pointCount` 像素特征匹配定位"转发..."菜单项并点击
5. 在转发窗口中输入 `key` 对应的关键词搜索目标群组
6. 点击第一个搜索结果，再点击发送按钮完成转发

### 适配不同分辨率/微信版本

如果默认坐标在你的屏幕上不准确，需要手动调整：

1. 将 `isDebug` 设为 `True` 开启调试模式
2. 调整 `dx`、`dy`、`imgWidth`、`imgHeight` 确保截图区域覆盖右键菜单
3. 调整 `search_x`、`search_y` 使其对准转发窗口中搜索结果的第一个匹配项
4. 调整 `sendbtn_x`、`sendbtn_y` 使其对准转发窗口的发送按钮
5. 如需适配新的菜单样式，菜单截图为：`screenshot.png`，每行黑点数量查看 `log`目录下的最新log文件。
